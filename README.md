Time Garden BookNest – Online Book Discovery & Shopping Portal

About the Project

BookNest is a Python-based online book discovery and shopping portal designed to help readers explore books, learn about their content, and purchase their favourite titles.
The platform aims to provide a simple and convenient experience for discovering books across different genres.

Objectives:

- Make book discovery easier for readers.
- Provide brief book synopses and author information.
- Allow users to search and explore books by category.
- Provide a convenient book ordering system.

Planned Features:

- Browse available books.
- Search books by title or author.
- Explore different book genres.
- View book descriptions, authors, and prices.
- Add books to a shopping cart.
- Place and manage orders.
- Generate basic sales and inventory reports.

Technologies Used:

- Python – Backend programming.
- Jupyter Notebook – Code development and execution.
- Streamlit – User interface.
- JSON – Data storage.
- GitHub – Version control and project management.

Project Structure:

The project will contain Python source code, a Jupyter Notebook, JSON data files, and project documentation.

Project Status:

Currently under development as part of a Python programming assignment.
